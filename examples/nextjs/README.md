# Next.js example

Use this folder for a minimal Next.js demo app that exercises:

- `/`
- `/dashboard`
- an optional login flow for `auth.setupScript`

Suggested scripts:

```json
{
  "scripts": {
    "dev": "next dev",
    "build": "next build",
    "start": "next start -H 127.0.0.1 -p 3000"
  }
}
```
